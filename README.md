# 跨学科研稿遴审

稿件的作者贡献、专家专长与回避声明按期收录。
演练资料使用虚构单位、人员与业务文字。资料以 UTF-8 JSON 给出，各文件按收到的顺序保存，正文中引述的名字和词形按原样保留。

## 资料格式

每份资料是记录数组。编号的作用范围是所在资料集，同一业务对象如有不同版本则另列记录。空字符串表示交接文件未填写，空数组表示未列条目。没填写的值无法代替明确的反面事实。

- `data/submissions.json` 保存id、版次、时间、标题、摘要、贡献声明。摘要和贡献声明由作者填写，版次按同一稿件递增。

- `data/roster.json` 保存id、姓名、单位、分组、专长声明、回避声明、名额。名额是本期可接邀请总数。姓名不是人员唯一标识。

- `data/directory.json` 保存id、姓名、单位、项目。稿件人员表含作者与共同署名单位。

- `data/bylines.json` 保存id、版次、人员、署名单位。一个稿件可以有多条署名记录。

- `data/desk.json` 保存id、稿件、版次、专家、动作、时间、内容。编辑收发件日志中的历史原文。

- `data/desk_rules.json` 保存id、原文。编辑部对回避周期、评审独立性和对外材料的约定。

## 阅读与运行

使用 Python 3.11.2 和标准库，无需安装第三方包。在仓库根目录可列出交接资料，或查看一条原始记录的所有版本。测试核查文本能原样读取和资料之间的关联。

```text
python3 -m corpus
python3 -m corpus submissions --id M1
python3 -m unittest discover -s tests -v
```
